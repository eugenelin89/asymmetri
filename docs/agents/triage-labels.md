# Triage labels

| Role and GitHub label | Meaning |
| --- | --- |
| `needs-triage` | A maintainer needs to evaluate the issue. |
| `needs-info` | The reporter needs to provide more information. |
| `ready-for-agent` | The specification is ready for an agent to implement. |
| `ready-for-human` | The work needs a human to implement it. |
| `wontfix` | The maintainer has declined the work. |
