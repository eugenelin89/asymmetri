# Natural dialogue browser evidence

Two actual, unretouched JPEG screenshots of the compiled local UBC application,
October 31, 2026. These show working conversation UI reached through ordinary
directory travel, walking and interaction controls. No generated marketing image,
real portrait or user attachment is used.

- [Desktop introduction](mitch-introduction-desktop.jpg), 1280×720: Mitch's short
  first-person introduction and follow-up choices.
- [Phone introduction](mitch-introduction-phone.jpg), 390×844: the complete short
  reply fits without scrolling through verification or model details.

The source and simulation metadata remain in optional disclosures. Browser checks
also covered typed introductions, educational replies, uncertainty, thanks,
goodbye, history, focus and tablet layout. These are viewport tests, not physical-
phone measurements. See [validation and release status](../../UBC_NATURAL_DIALOGUE_2026-10-31.md).
