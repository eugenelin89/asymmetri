## Decisions

- Use the existing GitHub Linux candidate workflow and established DigitalOcean
  whole-directory activation; retain the complete immediate predecessor.
- Preserve 192 MiB available-memory and 6 GiB free-disk floors. The first private
  smoke process was terminated by its memory guard before activation. Bound the
  temporary candidate heap to 80 MiB and repeat the full check with image optimization
  inside that guarded process. The successful repeat passed above the original floor.
- Preserve failed-attempt receipts. Address TCP TIME_WAIT in the socket preflight
  using address reuse, which still rejects an active listener.
- Keep deployed source/build identity separate from later documentation commits.
- Report procedural, representative architecture honestly; retain physical-device,
  sustained-performance and measured-geometry limitations.
