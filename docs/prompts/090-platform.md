## Lessons learned

Status projections must preserve an adopted method independently of list windows
or the latest status. Producer-to-consumer tests need exact projected records,
including rejection and next-day behavior. A failed environmental precondition
must remain visible even after a correctly established test passes. Resource
limits and immutable archive boundaries remain part of release acceptance.
